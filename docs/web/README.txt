SQ Cam — App Store 支持页 / 隐私政策页
========================================

本压缩包包含两个静态页面，需要发布到公网（腾讯云）。App Store 提交时必须填这两个 URL：

  privacy.html   →  隐私政策 URL（App Store Connect 必填，且必须与「App 隐私」问卷一致）
  support.html   →  支持 URL（App Store Connect 必填，审核员会点开）

------------------------------------------------------------
发布前必须替换两处占位符（两个文件里各有一处）
------------------------------------------------------------

1) 邮箱占位符      support@example.com
   → 替换为你们的真实支持邮箱（例如 support@yourdomain.com）
   → 两个文件里都要替换（隐私政策末尾、支持页顶部和常见问题里）

2) 公司名称占位符   COMPANY NAME
   → 替换为公司法定名称（版权归属，App Store 页面底部显示 © 2026 <名称>）

建议直接用编辑器全局替换，不要漏。

------------------------------------------------------------
发布要求
------------------------------------------------------------

- 必须公网可访问，**不需要登录**（审核员在国外直接打开）
- 必须是 text/html，浏览器能正常渲染
- 强烈建议 HTTPS
- 两个页面放在**同一目录**下（support.html 里有指向 privacy.html 的相对链接）
- 页面无外部依赖（CSS 内联、无外部字体/JS/图片），整目录直接托管即可

------------------------------------------------------------
发布后请回报以下两项（App Store Connect 要用）
------------------------------------------------------------

  隐私政策 URL: https://<域名>/<路径>/privacy.html
  支持 URL    : https://<域名>/<路径>/support.html

自检（发布方执行）：

  curl -sS -o /dev/null -w '%{http_code} %{content_type}\n' https://<域名>/<路径>/privacy.html
  curl -sS -o /dev/null -w '%{http_code} %{content_type}\n' https://<域名>/<路径>/support.html

期望输出形如： 200 text/html

再用浏览器无痕窗口打开两个链接，确认：
  - 不需要登录
  - 中文正常显示
  - 支持页里的「隐私政策」链接能跳到 privacy.html
